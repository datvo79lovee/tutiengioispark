# CSV Cleaner

Mini project của tuần 1. README này sẽ được hoàn thiện ở buổi 5.

## Mục tiêu

Đọc `orders.csv`, loại hoặc ghi nhận bản ghi không hợp lệ, tính tổng tiền và xuất `clean_orders.csv`.

## Cấu trúc

- `data/raw`: dữ liệu đầu vào.
- `data/processed`: kết quả chạy chương trình.
- `src`: mã nguồn.
- `tests`: trường hợp kiểm tra.
