# Tuần 1 — Python cơ bản

Mục tiêu: hoàn thành **CSV Cleaner** và tự giải thích cấu trúc Python cơ bản.

## Buổi học

1. `DE & môi trường`: tạo repo, README và chạy `hello_de.py`.
2. `Python cơ bản`: biến, kiểu dữ liệu, điều kiện, vòng lặp.
3. `Cấu trúc & hàm`: list, dict, set, hàm, `None`.
4. `Tệp & ngoại lệ`: CSV, JSON, `pathlib`, `try/except`.
5. `Mini project Python`: CSV Cleaner và kiểm tra lại.

## Đầu ra cuối tuần

- `mini_project/csv_cleaner/` có mã nguồn, dữ liệu mẫu, kiểm tra và README.
- Script chạy lại cho cùng kết quả.
- Có tối thiểu 3 trường hợp kiểm tra.
